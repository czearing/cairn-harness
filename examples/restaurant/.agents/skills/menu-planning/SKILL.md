name: menu-planning
description: Plan and delegate a coherent restaurant menu across specialists.
---

1. Record the menu theme, specialty, ingredients, constraints, and acceptance criteria in shared docs.
2. Split work by independent culinary specialty.
3. Create targeted TODO files with `to:` and `topic:` headers.
4. Let specialists work in parallel.
5. Send completed recipes to the tester with the full deliverable.
6. Update shared docs when decisions change.
